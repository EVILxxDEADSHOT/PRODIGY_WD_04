# Personal Portfolio Website

This is a personal portfolio website designed to showcase my skills, projects, and accomplishments as a web developer. 

-----------------------Features---------------------

- **Responsive Design**: Works on all screen sizes.
- **Home Page**: Captivating headline and professional photo.
- **About Me**: Background, education, and experience details.
- **Skills**: Highlights technical skills.
- **Projects**: Displays completed projects with links.
- **Contact**: Provides contact details and social links.

-----------------------Files-----------------------

- `index.html`: The HTML structure of the portfolio.
- `styles.css`: The CSS for styling.
- `script.js`: The JavaScript for optional interactivity.
- `README.md`: Project documentation.
